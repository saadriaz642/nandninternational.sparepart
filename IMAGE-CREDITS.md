# Image Credits

All photographs on this website are real photographs stored locally in
`assets/images/`. The website does not hotlink or load any image from an
external server at runtime. No AI-generated photographs are used anywhere
on this site.

Only resizing / JPEG recompression was applied to downloaded files, which
the licences permit. No photograph was altered, composited, or replaced,
and no photograph is presented as something it is not.
